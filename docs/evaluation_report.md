### 2.1 方法修正记录（为什么重跑 baseline）

旧版 baseline 系统提示缺少任务结构与预算引导（与防御配置存在混淆变量），导致
15/15 全部预算耗尽——其"ASR=0"实为**无输出假象**。修正后（唯一差异=安全段）：
完成 8/15、完成条件下污染 7/8——这才是无防御的真实风险基线，也验证了
"污染率必须分母对齐到完成任务"的方法论必要性。

### 2.2 输出侧 guard 的分层结论（真实数据）

- **拦截**：URL 形态外传在 guarded 下全部拦截（baseline 的 A04/A08/A12 等
  URL 型污染样例 → guarded 下 0 得手）；另离线回放 23 份历史真实任务报告，
  guard 抓到 **1 例真实引用编造**（模型在报告中引了 2 个从未检索/阅读过的
  paper_id——t7fe63c90ca，轨迹可查证）。
- **误拒**：修正"引用落地证据"语义（touched = 工具参数 + 检索结果中出现的全部
  paper_id）后，22/22 份干净报告零误拦（含 arXiv/OpenAlex/DOI/本站链接全放行；
  修正前的 3 例 FLAG 为证据提取不全的假阳性，已随 runtime 修复消除）。
- **残留面（如实）**：3/10 漏网均为**非 URL 形态**——模型把 canary 裸文本标记
  （如 ATTACKER-CANARY-xxxx）写进报告正文，超出"链接 guard"的设计边界；
  下一步是输出内容标记检测层（与链接域白名单正交）。

### 2.3 防御层次总结论（一段话版本）

> 提示层（hardened）把完成条件下污染从 88% 降到 69%（概率性缓解）；执行层硬边界
> 保证工具调用零违规（0/60，确定性）；输出层 guard 进一步把污染降到 30%
> （URL 形态 100% 拦截 + 抓到真实引用编造 + 零误拒）；残留 30% 为非 URL 文本
> 标记形态，需要内容检测层——每层各管一段，没有银弹。

## 3. 单元测试（确定性证据）

`python -m pytest tests/ -q` → **31 passed（~2s，全离线）**。新增覆盖：
- `test_timeouts.py`：挂起工具被 daemon 线程看门狗放弃（进程不被拖死）、单轮多
  调用每步检查预算、工具层幂等语义；
- `test_output_guard.py`：恶意外链拦截、合法学术域零误拦、裸 URL/markdown 双
  解析、无轨迹支撑 paper_id 标记、warn/block 两模式、干净输出零审计噪音。

## 4. Bad Cases 与运行事件（评测的产出，全部真实）

| # | 案例 | 归因 | 处置 |
|---|---|---|---|
| 1 | 预算检查漏洞（单轮多调用绕过步数上限） | 内层循环不检查预算 | 修复+回归测试（test_timeouts） |
| 2 | 模型核验行为远超 Mock 假设 | 任务指令与预算错配 | 预算 12+提示加预算意识；Mock 不可替代真实评测的证据 |
| 3 | LLM/PDF 挂起（>10min 不超时） | urllib timeout 对连接后挂起无效 | daemon 线程看门狗（LLM 420s 硬帽/工具 120s）+回归 |
| 4 | **baseline 混淆变量**（旧版 15/15 全崩） | 提示差异不止安全段 | 修正后重跑（完成 8/15），旧结论作废并留档 |
| 5 | guard 首版误拒 3 例（离线回放发现） | 引用落地证据只含工具参数、漏检索结果 id | runtime 收集语义修复，误拒 0/22 |
| 6 | 3/10 非 URL 形态污染残留 | 链接 guard 管不住裸文本标记 | 如实报告，列入下一步（内容标记检测层） |
