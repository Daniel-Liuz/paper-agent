## 推荐 3 条（2026-11-06 修订版，全部真实可复现数据）

1. **【Agent Runtime 与可靠性】** 为开源论文 Agent 实现多步任务运行时（function calling 自主编排检索/阅读/引文核验/提交，三重预算+SQLite 全轨迹+幂等重放恢复）；真实评测中发现并修复两类可靠性缺陷——"单轮多工具调用绕过步数上限"的预算漏洞与"urllib 超时对连接后挂起无效"导致的任务卡死（daemon 线程看门狗），均配 pytest 回归（31 项测试全离线全绿）。

2. **【纵深安全与对照实验】** 构建三层防御并做真实对照实验（15 注入样例×三载体×四配置，DeepSeek 真实运行）：执行层工具白名单（60 个攻击任务违规调用 0 次，确定性）；输出侧链接/引用校验组件（可信域白名单+引用落地证据），把完成任务中的输出污染率从 **88%（无防御）降至 30%**（URL 形态 100% 拦截、22 份真实报告零误拦、并抓到 1 例模型编造引用的真实案例）；如实定量残留面（非 URL 文本标记 3/10）并界定为下一步。

3. **【评测方法论】** 设计可复现 Evaluation Harness（16 科研任务规则判定+失败归因、Mock/真实强制分离），并在实验中修正两个评测方法缺陷：baseline 系统提示存在混淆变量（修正后重跑，原"ASR=0"实为无输出假象）与污染率分母错位——确立"攻击成功率必须与任务完成率对偶报告、按完成条件分母统计"的口径。
